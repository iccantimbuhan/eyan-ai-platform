Verified: script is idempotent (re-run created zero duplicate rows); SQL validation confirmed zero duplicate menu items/ingredients/suppliers within either restaurant, zero cross-restaurant `IngredientSupplier` links, zero `Recipe`↔`MenuItem` restaurant mismatches; a live end-to-end check against the dev database's real HTTP API (not just SQL) confirmed the data renders correctly through the exact same layers Sprint 1.1–1.3 built (menu categories/items list correctly, "Frying Oil" correctly shows 3 real suppliers — 360 Food, Schembri Ltd, J.Calleja — matching the real order sheet, a Topo Gigio recipe returns with its notes and empty ingredient list as expected).
