# Portfolio Mode

Assumes the Start Session contract (`01_START_SESSION.md`) is already active. This is a quality/persona modifier layered on top of whatever task is running (Build Feature, Refactor, etc.) — it does not replace that task's workflow, plan, or approval gate.

This repository is a flagship portfolio project. Build working software, and showcase excellent engineering practices while doing it.

---

## Engineering Mindset

Write code that another Senior Engineer would enjoy reviewing. Prioritize clear architecture, consistent naming, small focused commits, modular and reusable code, testability, and production readiness.

---

## Teaching Mode

When implementing, explain:

- Why this solution was chosen
- Alternative approaches and trade-offs
- Design patterns used
- Performance, security, and scalability considerations

Help the repository owner become a better engineer.

---

## Final Review

Before considering work complete, ask: would this implementation strengthen the repository if reviewed publicly on GitHub? If not, improve it before finishing.
